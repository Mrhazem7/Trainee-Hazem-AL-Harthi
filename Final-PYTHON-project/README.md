# منظم الملفات (File Organizer)

مشروع Python (9) — تطبيق سطر أوامر (CLI) بأسلوب البرمجة الكائنية (OOP) لتنظيم ملفات أي مجلد
تلقائيًا في مجلدات فرعية حسب نوعها (صور، مستندات، فيديوهات، صوتيات، أرشيف، أكواد، أخرى).

## الفكرة

المستخدم يحدد مسار مجلد (مثلاً مجلد التنزيلات)، والبرنامج يفحص كل الملفات الموجودة مباشرة
بداخله، يصنّف كل ملف حسب امتداده، وينقله إلى مجلد فرعي مناسب. كل عملية تنظيم تُسجَّل في ملف
`organizer_log.json`، مما يسمح لاحقًا بعرض سجل العمليات أو التراجع (Undo) عن آخر عملية وإرجاع
كل الملفات إلى مكانها الأصلي.

## كيف تحقق المتطلبات المطلوبة

- **استخدام البرمجة الكائنية (OOP):** المشروع مبني على 3 كلاسات رئيسية بمسؤوليات منفصلة:
  - `FileClassifier` — يحدد فئة كل ملف حسب امتداده (`file_organizer/classifier.py`).
  - `OperationLogger` — يقرأ ويكتب سجل العمليات (`file_organizer/logger.py`).
  - `FileOrganizer` — المنطق الرئيسي: التنظيم والتراجع (`file_organizer/organizer.py`).
- **قراءة وكتابة الملفات لحفظ البيانات:**
  - `config.json`: خريطة الفئات والامتدادات (تُقرأ عند بدء التشغيل، وتُنشأ تلقائيًا إن لم تكن موجودة).
  - `organizer_log.json`: سجل كل عمليات النقل (قراءة وكتابة عند كل تنظيم/تراجع، بصيغة JSON).
- **معالجة الأخطاء المتوقعة (Exceptions):** استثناءات مخصصة في `file_organizer/exceptions.py`
  يتم رفعها والتقاطها بشكل واضح بدل انهيار البرنامج، مثل:
  - مسار مجلد غير موجود / ليس مجلدًا (`InvalidDirectoryError`).
  - مجلد لا يحتوي على أي ملفات قابلة للتنظيم (`EmptyDirectoryError`).
  - ملف `config.json` تالف أو بصيغة JSON غير صحيحة (`ConfigError`).
  - ملف السجل تالف (`LogError`).
  - محاولة التراجع بدون وجود عملية سابقة (`UndoError`).
  - أخطاء نظام الملفات أثناء نقل ملف واحد (صلاحيات، ملف مستخدم من برنامج آخر...) تُلتقط لكل ملف
    على حدة بحيث لا تتوقف العملية بالكامل بسبب ملف واحد فقط.

> ملاحظة على صيغة الحفظ: تم استخدام **JSON** لكل من ملف الإعدادات وملف السجل، لأنها الصيغة
> الأنسب لبيانات منظَّمة (Structured Data) مثل خرائط الفئات وقوائم عمليات النقل، وهي مدعومة
> مباشرة في مكتبة بايثون القياسية (`json`) دون الحاجة لأي مكتبات خارجية.

## بنية المشروع

```
file_organizer/
├── main.py                    # نقطة تشغيل البرنامج + قائمة سطر الأوامر (CLI)
├── config.json                # إعدادات فئات التصنيف (يُنشأ تلقائيًا إن لم يكن موجودًا)
├── file_organizer/            # الحزمة الرئيسية (الكلاسات)
│   ├── __init__.py
│   ├── classifier.py          # كلاس FileClassifier
│   ├── logger.py              # كلاس OperationLogger
│   ├── organizer.py           # كلاس FileOrganizer
│   └── exceptions.py          # الاستثناءات المخصصة
├── example_output/            # مثال فعلي على البيانات المخرجة (راجع القسم أدناه)
│   ├── console_example.txt
│   └── organizer_log_example.json
├── .gitignore
└── README.md
```

لا توجد أي مكتبات خارجية مطلوبة — البرنامج يعمل بمكتبة بايثون القياسية فقط
(Python 3.7 أو أحدث).

## طريقة التشغيل

```bash
python main.py
```

ستظهر قائمة تفاعلية:

```
1) تنظيم مجلد
2) التراجع عن آخر عملية تنظيم
3) عرض سجل العمليات السابقة
4) عرض فئات التصنيف الحالية
5) خروج
```

- اختر **1** ثم أدخل مسار المجلد الذي تريد تنظيمه (مثلاً `/home/user/Downloads`).
- اختر **2** للتراجع عن آخر عملية تنظيم وإرجاع كل الملفات لمكانها.
- اختر **3** لعرض تاريخ كل عمليات التنظيم التي تمت.
- اختر **4** لعرض الفئات والامتدادات المعرّفة حاليًا في `config.json`.

يمكنك تعديل `config.json` يدويًا لإضافة فئات أو امتدادات جديدة حسب حاجتك.

## مثال على البيانات المخرجة

داخل مجلد `example_output/` نتيجة تشغيل فعلي على مجلد تجريبي يحتوي 8 ملفات بامتدادات مختلفة:

- `console_example.txt`: نسخة كاملة من مخرجات الطرفية (Console) قبل التنظيم وأثناءه وبعده،
  تشمل تنفيذ التنظيم، وعرض السجل، وعرض الفئات.
- `organizer_log_example.json`: محتوى ملف `organizer_log.json` الفعلي بعد تنفيذ عملية
  التنظيم، ويوضح شكل البيانات المحفوظة (الوقت، المجلد، الملفات المنقولة وفئة كل ملف).

## اختبارات تمت يدويًا

تم اختبار البرنامج على الحالات التالية والتأكد من أن كل حالة تُعطي رسالة واضحة بدون انهيار:

- تنظيم مجلد يحتوي ملفات متعددة الأنواع (يشمل أسماء ملفات بالعربية).
- إدخال مسار غير موجود.
- تنظيم مجلد فارغ.
- وجود ملف بنفس الاسم مسبقًا في مجلد الوجهة (يتم إعادة تسميته تلقائيًا بإضافة رقم).
- التراجع عن آخر عملية تنظيم وإرجاع الملفات لمكانها الأصلي.
- تلف ملف `config.json` (JSON غير صالح).
- تلف ملف `organizer_log.json`.
