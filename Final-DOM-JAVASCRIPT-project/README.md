تطبيق ويب تفاعلي مبني بـ **Vanilla JavaScript** (بدون أي framework)، ضمن سلسلة مشروع "DOM ومقدمة في JavaScript".

## ✅ المتطلبات المطبّقة

| المتطلب | كيف تم تنفيذه |
|---|---|
| **DOM Manipulation** | إنشاء/حذف عناصر `<li>` ديناميكياً في سجل العمليات (`renderHistory`)، وتحديث نص الشاشة عند كل تفاعل |
| **Event Handling** | حدث `click` واحد مفوَّض (Event Delegation) على لوحة الأزرار كاملة + دعم لوحة المفاتيح الفعلية (`keydown`) |
| **State Management** | كائن `state` مركزي يحتفظ بالرقم الحالي، السابق، العملية، وسجل العمليات — منفصل تماماً عن الـ DOM، ويُعاد رسم الواجهة من الحالة عبر `render()` |

## 🧮 الميزات
- العمليات الأربع الأساسية (+ − × ÷) مع دعم سلسلة عمليات متتالية
- معالجة القسمة على صفر (تظهر "خطأ" بدل الانهيار)
- زر حذف آخر رقم (⌫) وزر مسح كامل (C)
- سجل عمليات قابل للفتح/الإغلاق مع إمكانية مسحه
- دعم كامل للوحة المفاتيح الفعلية (أرقام، عمليات، Enter، Backspace، Escape)

## ▶️ التشغيل محلياً
لا حاجة لأي تثبيت — فقط افتح `index.html` في المتصفح، أو استخدم أي سيرفر بسيط:
```bash
npx serve .
```
