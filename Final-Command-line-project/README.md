# 🗂️ منظم الملفات التلقائي (File Organizer) — سطر الأوامر

سكربت **Bash** بسيط وعملي يقوم بترتيب الملفات داخل أي مجلد إلى مجلدات فرعية
حسب امتدادها (`pdf`, `txt`, `jpg`, `csv`, ...)، مع تسجيل كل خطوة في ملف سجل (log).

---

## 💡 الفكرة

بدل ما ترتب ملفاتك يدوياً، السكربت يفحص مجلد معيّن، ولكل ملف:

1. يحدد امتداده.
2. ينشئ مجلد فرعي باسم `الامتداد_files` إذا ما كان موجود.
3. ينقل الملف إليه.
4. يسجّل العملية (وقت + اسم الملف + الوجهة) في `organize.log`.

---

## ✅ المتطلبات المُحقّقة

| المتطلب | كيف تحقق في السكربت |
|---|---|
| كتابة سكربت Bash يؤدي مهمة مفيدة فعلياً | تنظيم الملفات تلقائياً حسب الامتداد |
| استخدام إعادة توجيه الدخل/المخرجات (`>` و `>>`) | `>` لإنشاء ملف السجل من جديد في بداية كل تشغيل، و`>>` (عبر `tee -a`) لإضافة كل سطر جديد للسجل |
| استخدام الأنابيب (`\|`) | `find ... \| while read -r file` لمعالجة كل ملف، و`find ... \| wc -l` لحساب عدد الملفات في كل مجلد |
| تسجيل العمليات في ملف سجل (log) | كل عملية نقل، نجاح أو فشل، تُسجَّل في `organize.log` داخل المجلد المستهدف مع الوقت والتاريخ |

---

## ⚙️ طريقة التشغيل

```bash
# أعطِ الصلاحية للتنفيذ (مرة وحدة بس)
chmod +x organize.sh

# شغّل السكربت على مجلد معيّن
./organize.sh /path/to/your/folder

# أو بدون تحديد مسار، بيستخدم المجلد الحالي
./organize.sh
```

بعد التشغيل:
- بتلاقي داخل المجلد المستهدف مجلدات فرعية مثل `pdf_files`, `txt_files`, `jpg_files` ...
- وبيصير عندك ملف `organize.log` فيه تفاصيل كل عملية نقل صارت.

```

├── README.md       # هذا الملف
└── screenshot.png  # لقطة شاشة تثبت التشغيل الفعلي (تُضاف عند التسليم)
```

## 📝 ملاحظات تقنية

- السكربت يتجاهل نفسه وملف السجل عند الفحص، فما يحاول ينقلهم.
- الملفات بدون امتداد (زي `README`) تُنقل تلقائياً إلى مجلد `no_extension_files`.
- امتدادات الملفات تُحوَّل لأحرف صغيرة، فمثلاً `photo.JPG` و `photo.jpg` ينتهي بهما المطاف بنفس المجلد `jpg_files`.
- استُخدم `set -uo pipefail` لجعل السكربت أكثر أماناً (يوقف عند متغيرات غير معرّفة أو فشل داخل الأنابيب).
