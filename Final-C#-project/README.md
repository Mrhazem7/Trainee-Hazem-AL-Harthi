# نظام إدارة مخزون بسيط - C#

تطبيق Console بلغة C# لإدارة مخزون بسيط، مبني بأسلوب البرمجة الكائنية (OOP).

## الميزات

- تعريف عنصر المخزون ككائن (Object) من class باسم `Item`.
- إضافة عناصر جديدة للمخزون.
- عرض جميع العناصر الموجودة في المخزون.
- تعديل كمية عنصر موجود عن طريق اسمه.
- الخروج من البرنامج.

## طريقة التشغيل

1. تأكد إن .NET SDK مثبت عندك.
2. افتح Terminal داخل مجلد المشروع.
3. نفذ الأمر:

```
dotnet run
```

4. اختر رقم العملية من القائمة الظاهرة وتابع التعليمات على الشاشة.

## هيكل المشروع

- `Program.cs` — يحتوي على class `Item` (تمثيل عنصر المخزون) وclass `Program` (منطق البرنامج الرئيسي: القائمة، الحلقات، والدوال).
- `InventoryApp.csproj` — ملف المشروع.
