# مشروع SQL 103

## الوصف
مشروع مكمّل لمستوى SQL الثاني، يطبق مفاهيم متقدمة في قواعد البيانات. يشمل إنشاء علاقات بين جداول المعلمين والطلاب والمواد الدراسية، إنشاء Procedure باسم student_info لعرض بيانات الطلاب والمواد المشتركة بينهم، إنشاء وحذف Views لعرض معلومات المعلمين والمواد، بالإضافة إلى إنشاء وحذف Index للبحث السريع عن أسماء الطلاب أبجديًا.

## المتطلبات
MySQL Workbench أو أي برنامج يدعم قواعد بيانات SQL

## طريقة التشغيل
افتح البرنامج MySQL Workbench، افتح ملف المشروع، ثم نفذ الأوامر بالترتيب من البداية للنهاية
