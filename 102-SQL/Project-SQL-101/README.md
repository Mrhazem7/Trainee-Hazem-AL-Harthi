# نظام إدارة بيانات مدرسية (SQL 101)

## الوصف
مشروع قاعدة بيانات لمدرسة ثانوية باستخدام SQL. يقوم بإنشاء قاعدة بيانات مركزية تضم معلومات الطلاب والمعلمين والمواد الدراسية. يشمل المشروع إنشاء الجداول، إدخال بيانات تجريبية، عرض واستعلام البيانات بطرق مختلفة، وتعديل السجلات باستخدام أوامر SQL.

## الجداول المستخدمة
جدول الطلاب Students، جدول المعلمين Teachers، جدول المواد Subjects

## المتطلبات
MySQL Workbench أو أي برنامج يدعم قواعد بيانات SQL

## طريقة التشغيل
افتح البرنامج MySQL Workbench، افتح ملف Project-sql-101.sql، ثم نفذ الأوامر بالترتيب من البداية للنهاية لإنشاء قاعدة البيانات وتعبئتها بالبيانات
