# مشروع SQL 102

## الوصف
مشروع مكمّل لمشروع SQL 101، يطبق استعلامات متقدمة على قاعدة بيانات المدرسة. يشمل إنشاء جداول فرعية للطلاب المتفوقين والطلاب غير المجتازين، استخدام الدوال التجميعية (AVG, MAX, MIN)، دوال النصوص والأرقام (String Functions, Numeric Functions)، بالإضافة إلى استعلامات فرز وتحديث بيانات الطلاب.

## المتطلبات
MySQL Workbench أو أي برنامج يدعم قواعد بيانات SQL

## طريقة التشغيل
افتح البرنامج MySQL Workbench، افتح ملف المشروع، ثم نفذ الأوامر بالترتيب من البداية للنهاية
