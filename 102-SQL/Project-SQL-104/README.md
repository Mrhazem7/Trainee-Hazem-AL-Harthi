# المشروع النهائي - قاعدة بيانات موقع تواصل اجتماعي

## الوصف
مشروع قاعدة بيانات يحاكي موقع تواصل اجتماعي (مشابه لتويتر). يقوم بتخزين بيانات المستخدمين، التغريدات، والمتابعين. يشمل المشروع رسم ER Diagram لاستنتاج العلاقات والأعمدة قبل التطبيق، إنشاء قاعدة بيانات وجداول مترابطة بعلاقات Foreign Key، تشفير الرقم السري للمستخدم باستخدام MD5، بالإضافة إلى إنشاء Procedures لإنشاء حساب مستخدم جديد (createAccount) ومتابعة مستخدم آخر (User_Follow).

## المتطلبات
MySQL Workbench أو أي برنامج يدعم قواعد بيانات SQL



## طريقة التشغيل
افتح البرنامج MySQL Workbench، افتح ملف المشروع، ثم نفذ الأوامر بالترتيب من البداية للنهاية
