# مشروع مكتبة Bookstore

برنامج بسيط بلغة JavaScript لإدارة مكتبة كتب: إضافة، تعديل، حذف، استعلام، وبيع الكتب مع إصدار فاتورة.

## تخزين البيانات

يتم تخزين الكتب في **مصفوفة ثنائية الأبعاد (2D Array)**، كل صف يمثل كتاب بالترتيب التالي:

```
[ Book Id, Title, Author, Price, Quantity ]
```

## الدوال المتوفرة

| الدالة | وظيفتها |
|---|---|
| `addBook(id, title, author, price, quantity)` | إضافة كتاب جديد |
| `editBook(id, title, author, price, quantity)` | تعديل بيانات كتاب (مرر `undefined` لأي قيمة ما تبي تغيرها) |
| `deleteBook(id)` | حذف كتاب برقمه |
| `displayBooks()` | عرض كل الكتب |
| `searchBook(id)` | الاستعلام عن كتاب برقمه (Id, Title, Author) |
| `sellBook(title, quantity, balance)` | بيع كتاب وطباعة فاتورة |

## شروط عملية البيع

قبل إتمام أي عملية بيع، يتحقق البرنامج من:
1. أن الكتاب موجود.
2. أن الكمية المطلوبة متوفرة في المخزون.
3. أن رصيد العميل يكفي للشراء.

إذا تحققت الشروط الثلاثة، يتم خصم الكمية من المخزون وطباعة فاتورة الشراء.

## طريقة التشغيل

```bash
node bookstore.js
```

في نهاية الملف قسم تجربة (Testing) يوضح كيف تُستخدم كل دالة، تقدر تعدل عليه أو تحذفه وتكتب أوامرك الخاصة.
