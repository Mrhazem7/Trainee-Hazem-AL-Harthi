# نظام إدارة مكتبة صغيرة (Library Management System)

## وصف المشروع
برنامج بلغة Java يعمل من خلال الطرفية (Console)، يساعد على إدارة كتب مكتبة صغيرة. 
يقدر المستخدم يضيف كتب جديدة، يعرض كل الكتب المتوفرة، يبحث عن كتاب معين، يحذف كتاب، 
ويسجل عمليات الاستعارة والإرجاع — كل هذا من خلال قائمة تفاعلية بسيطة.

## طريقة عمل البرنامج (شرح مبسط)
1. البرنامج يعرض قائمة فيها 7 خيارات (إضافة، عرض، بحث، حذف، استعارة، إرجاع، خروج).
2. المستخدم يكتب رقم العملية اللي يبيها ويضغط Enter.
3. حسب الاختيار، البرنامج يطلب بيانات إضافية (زي عنوان الكتاب أو رقم الـ ID).
4. البرنامج ينفذ العملية ويطبع نتيجة واضحة (نجاح ✅ أو خطأ ⚠️).
5. القائمة ترجع تطلع من جديد، وتتكرر العملية لين المستخدم يختار "خروج".

## هيكلة المشروع (الكلاسات)
- **Book.java**: يمثل بيانات الكتاب الواحد (ID، العنوان، المؤلف، حالة التوفر).
- **Library.java**: يحتوي على قائمة الكتب (ArrayList) وكل العمليات (إضافة، عرض، بحث، حذف، استعارة، إرجاع).
- **Main.java**: يحتوي على القائمة التفاعلية (Menu) اللي يتفاعل معها المستخدم، مع معالجة الأخطاء (try-catch).

## المميزات
- إضافة كتاب جديد بـ ID وعنوان ومؤلف.
- عرض كل الكتب الموجودة بالمكتبة مع حالتها (متاح / مستعار).
- البحث عن كتاب بالعنوان.
- حذف كتاب برقم الـ ID.
- تسجيل استعارة وإرجاع الكتب.
- معالجة الأخطاء: لو المستخدم أدخل قيمة غير صحيحة (مثل حرف بدل رقم)، البرنامج ما ينهار، بس يطبع رسالة خطأ ويطلب الإدخال من جديد.

## طريقة التشغيل
1. تأكد إن Java مثبت على جهازك.
2. افتح الطرفية (Terminal) داخل مجلد المشروع.
3. نفذ الأمر التالي لترجمة الملفات:
javac Main.java
4. بعدها شغل البرنامج:
java Main
5. اتبع التعليمات اللي تظهر بالقائمة.

## ملاحظة
البرنامج يدعم اللغة العربية بشكل كامل عبر ترميز UTF-8. لو ظهر النص العربي بشكل معكوس 
في بعض الطرفيات القديمة (مثل PowerShell الكلاسيكي)، هذا قصور بعرض النصوص ثنائية الاتجاه 
(RTL) في تلك الطرفية، ولا يؤثر على عمل البرنامج، ويظهر بشكل صحيح في الطرفيات الحديثة 
مثل Windows Terminal.
