# نموذج تسجيل (Registration Form) — مشروع PHP

تطبيق ويب بسيط بلغة PHP يقوم بوظيفة **CRUD** (إضافة، عرض، حذف) لنموذج تسجيل بيانات المستخدمين،
مع التحقق الكامل من صحة المدخلات (Validation) قبل حفظها.

## الميزات

- **نموذج إدخال (Form):** يستقبل الاسم، البريد الإلكتروني، رقم الجوال، والعمر.
- **التحقق من صحة البيانات (Validation):**
  - الاسم: مطلوب، حروف فقط.
  - البريد الإلكتروني: مطلوب، صيغة بريد صحيحة.
  - رقم الجوال: مطلوب، أرقام فقط (8-15 رقم).
  - العمر: مطلوب، رقم بين 1 و120.
- **تخزين البيانات:** في ملف `data/registrations.json` بصيغة JSON.
- **عرض السجلات:** جدول يعرض كل السجلات المسجّلة.
- **حذف سجل:** إمكانية حذف أي سجل من القائمة.

## هيكل المشروع

```
project/
├── index.php          # الصفحة الرئيسية (النموذج + عرض السجلات + المعالجة)
├── functions.php       # كل الدوال (Validation, Save, Get, Delete)
├── data/
│   └── registrations.json   # ملف تخزين البيانات
└── README.md
```

## طريقة التشغيل

### المتطلبات
- PHP 7.4 أو أحدث (يُفضّل PHP 8+) مثبت على جهازك.

### الخطوات

1. افتح الـ Terminal داخل مجلد المشروع.
2. شغّل السيرفر المدمج في PHP بالأمر التالي:

   ```bash
   php -S localhost:8000
   ```

3. افتح المتصفح واذهب إلى:

   ```
   http://localhost:8000
   ```

4. جرّب تعبئة النموذج، وستلاحظ:
   - لو تركت حقل فارغ أو أدخلت بيانات غير صحيحة → ستظهر رسالة خطأ تحت الحقل المعني.
   - لو أدخلت بيانات صحيحة → سيتم حفظ السجل وعرضه في الجدول أسفل النموذج.
   - يمكنك حذف أي سجل بالضغط على رابط "حذف" بجانبه.
