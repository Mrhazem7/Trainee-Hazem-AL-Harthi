# مشروع صفحة دورة تعلم CSS

## الفكرة
صفحة هبوط (Landing Page) بسيطة لدورة تعليمية عن CSS، مصممة على شكل **نافذة محرر أكواد** (Code Editor)، عشان تعكس موضوع الدورة نفسه بصريًا.

## الشكل العام
- شريط تنقل علوي ثابت فيه اسم الدورة وروابط (الرئيسية / عن الدورة / انضم الآن).
- قسم رئيسي (Hero) على شكل نافذة كود فيها:
  - شريط علوي بثلاث نقط ملونة (زي نوافذ الماك).
  - عنوان الصفحة مكتوب بصيغة قاعدة CSS حقيقية: `color: احترافي;`.
  - فقرة وصف قصيرة عن الدورة.
  - زرار "ابدأ التعلم الآن".
- ثلاث بطاقات صغيرة توضح مميزات الدورة (تطبيقي / مبسّط / تدريجي).
- خلفية فاتحة مع توهجات لونية خفيفة ومتحركة (أنيميشن بسيط).
- تذييل (Footer) بسيط في الآخر.

## الخصائص المطلوبة واستخدامها

| العنصر | الخصائص المستخدمة |
|---|---|
| خلفية الصفحة | `background-image` (تدرج دائري متحرك) |
| العنوان الرئيسي | `font-family`, `text-align`, `color`, `position` |
| زر الانضمام | `border-radius`, `color`, `background`, `position` |
| قائمة التنقل | `margin`, `padding`, `position`, `background-color` |
