# دِقّة — تطبيق حجز خدمات صيانة واستشارات عامة

مشروع UX/UI (7) — دورة UX/UI

## الفكرة
تصميم واجهة وتجربة استخدام لتطبيق جوال بسيط يتيح للمستخدم حجز مواعيد لخدمات
الصيانة العامة (كهرباء، سباكة، تكييف) والاستشارات، بشكل موثوق وسريع.

## المشكلة
يواجه المستخدمون صعوبة في العثور على فنيين أو مستشارين موثوقين، ومقارنتهم،
وحجز موعد مؤكد دون الحاجة إلى مكالمات هاتفية متكررة أو انتظار طويل للرد.

## الحل
تطبيق «دِقّة» يتيح تصفح مزودي الخدمة حسب الفئة، مقارنتهم بالتقييم والتوفر،
اختيار تاريخ ووقت محددين، وإتمام الحجز فورًا مع تأكيد مباشر وتفاصيل واضحة.

## خطوات التفكير التصميمي
1. تحديد المشكلة
2. الحل المقترح
3. النموذج الأولي (Wireframe) — مجلد `wireframes/`
4. التصميم النهائي (UI) — مجلد `final-design/`

## الشاشات
1. **تسجيل الدخول** — إدخال البريد الإلكتروني
2. **رمز التحقق (OTP)** — تأكيد الدخول برمز مرسل للبريد
3. **الشاشة الرئيسية** — تصفح الفئات ومزودي الخدمة الأعلى تقييمًا
4. **شاشة تفاصيل مقدم الخدمة والحجز** — اختيار التاريخ والوقت
5. **شاشة تأكيد الحجز** — ملخص الموعد وحالة الحجز
