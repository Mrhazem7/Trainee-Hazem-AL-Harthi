نبذة

من أنا، وماذا أتقن

اسمي حازم، مهتم بتطوير الألعاب والتطبيقات، وبدأت رحلتي بتعلّم أساسيات HTML و CSS لبناء واجهات مشاريعي، وSQL لتنظيم بياناتها، وصولًا إلى برمجة منطق الألعاب بلغة C++ وتطويرها عبر محرك Unreal Engine 5، مع تصميم عناصرها ثلاثية الأبعاد باستخدام Blender.

أستمتع بتحويل فكرة بسيطة إلى منتج حقيقي يعمل بسلاسة، وأحرص دائمًا على أن يكون الكود مرتّبًا وواضحًا وقابلًا للقراءة من أي مطوّر آخر بسهولة.

  • HTML

    بناء هيكل دلالي (Semantic) صحيح باستخدام العناصر المناسبة لكل محتوى.

  • CSS

    تنسيق متجاوب (Responsive) عبر Flexbox و Grid لجميع أحجام الشاشات.

  • SQL

    تصميم واستعلام قواعد البيانات لتخزين بيانات الألعاب والتطبيقات.

  • C++

    برمجة منطق الألعاب وإدارة الأداء بكفاءة داخل محرّكات الألعاب.

  • Blender

    نمذجة وتجسيم عناصر ثلاثية الأبعاد (3D) لاستخدامها في الألعاب والتطبيقات.

  • Unreal Engine

    بناء وتطوير مراحل الألعاب وربط منطق اللعب داخل محرك Unreal Engine 5.
