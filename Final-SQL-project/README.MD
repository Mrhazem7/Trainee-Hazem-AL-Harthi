# Small Store SQL Project

مشروع قاعدة بيانات لمتجر صغير، يحتوي على جداول مترابطة واستعلامات تشغيلية على البيانات.

## الفكرة

تصميم قاعدة بيانات تُدير عمليات متجر صغير: العملاء، المنتجات، الطلبات، وتفاصيل كل طلب — مع كتابة استعلامات تحليلية على هذه البيانات.

## هيكل قاعدة البيانات

| الجدول | الوصف |
|---|---|
| `Customers` | بيانات العملاء (الاسم، البريد، الهاتف، العنوان) |
| `Products` | بيانات المنتجات (الاسم، السعر، الكمية المتوفرة) |
| `Orders` | رأس الطلب (رقم الطلب، العميل، تاريخ الطلب) |
| `Order_Details` | تفاصيل كل طلب (المنتج، الكمية، سعر الوحدة) — جدول وسيط بين Orders و Products |

### العلاقات

- **Customers → Orders**: علاقة واحد إلى متعدد (عميل واحد يملك طلبات كثيرة)
- **Orders ↔ Products**: علاقة متعدد إلى متعدد عبر جدول `Order_Details`

راجع `ERD.png` لرسم توضيحي كامل للعلاقات.

## الملفات

| الملف | المحتوى |
|---|---|
| `schema.sql` | إنشاء قاعدة البيانات، الجداول، المفاتيح، الفهرس (Index)، والإجرائية المخزّنة (Procedure) |
| `queries.sql` | بيانات تجريبية + 5 استعلامات تحليلية |
| `ERD.png` | رسم تخطيطي للعلاقات بين الجداول |

## الاستعلامات المضمّنة

1. عرض كل الطلبات مع اسم العميل (`JOIN`)
2. عرض تفاصيل كل طلب (منتج، كمية، سعر) (`JOIN` متعدد الجداول)
3. إجمالي المبيعات لكل عميل (`SUM` + `GROUP BY`)
4. المنتجات الأكثر مبيعًا (`COUNT` + `SUM` + `GROUP BY`)
5. متوسط قيمة الطلب لكل عميل (`AVG` + `GROUP BY`)

## طريقة التشغيل

1. نفّذ `schema.sql` أولًا لإنشاء قاعدة البيانات والجداول
2. نفّذ `queries.sql` لإدخال البيانات التجريبية وتشغيل الاستعلامات
